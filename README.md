## 💡 Key Takeaways & Best Practices

1. **Optimize Every Solution:** Always start with the brute-force approach, then refactor to optimize both Time and Space complexities.
2. **Document the Intuition:** Write down *why* a specific approach (like two-pointers vs. hash maps) was chosen inside the problem's local README.
3. **Spaced Repetition:** Re-visit "Hard" or tricky "Medium" problems 1-2 weeks after the first solve to verify retention.
